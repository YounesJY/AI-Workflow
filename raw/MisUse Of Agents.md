= CONTEXT

===============

-> TAKE CARE OF YOUR AGENT.md/CLAUDE.md

-> Not having one is better than having a bad one

-> Don't generate this file using your agent, this file needs to be reviewed manually and modified as needed and not taken directly from your AI

-> a 20 line of this file generate by you is better than 150 generated by AI and not reviewd , and since this file is **being loaded to your Agent context** it should be short as needed around 100 line if possible

-> Due to the context rot, never make more than one long feature withing a since session because the quality of your agent context is decreasing over time, goes as FeaturePerSession or at least use Compaction , both are better than making all your features within one single sessions

-> Don't ask for a very big task at once "like build me platform that does this and this".Instead, ask for small features so the Agent will focus on that specific one and error catching is better and easy

-> Do not use your primary agent to do the ask. Instead, ask him to spawn subAgents and delegate them the work to save you the context clean (even if this will consume more tokens) so the quality will remain high compared to single agent work
